Features

📚

Multi-Module Support

Load and display SWORD Bible modules including RawText, zText, RawCom, zCom, RawLD, and zLD formats. Access thousands of Bible translations.

🔍

Powerful Search

Case-insensitive text search with scope selection (All, OT, NT, Current Book). Full-text indexing with Tantivy search engine.

📝

Notes & Highlights

Personal notes on verses, 5 highlight colors, bookmarks with labels and folders. All persisted in SQLite database.

🔤

Strong's Numbers

Hebrew and Greek Strong's concordance lookup with popup definitions. Understand the original languages.

📊

Interlinear Display

Word-by-word Hebrew/Greek with original text, transliteration, morphology, Strong's numbers, and English gloss.

📖

Commentary & Lexicon

Commentary integration synced with current verse. Dictionary/lexicon lookup with search and A-Z browse.

🔀

Parallel View

Side-by-side translation comparison. Compare multiple Bible versions to deepen understanding.

🎨

Beautiful Themes

Dark, Light, Sepia, and High Contrast themes. Adjustable font scaling and line height for comfortable reading.

✝️

Cross-References

Scripture cross-reference display with clickable references and popup preview. Discover connected passages.

📅

Reading Plans

Pre-built Bible reading plans: 1-year, 90-day NT, Gospels, Psalms/Proverbs, Chronological. Track your progress.

🙏

Prayer List

Prayer request tracking linked to verses. Mark requests as answered, organize by categories.

📓

Study Journal

Personal Bible study journal. Create entries, link to verses, add tags for organization.
